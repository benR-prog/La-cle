# La Clé — Atlas cosmo-théurgique

*Un outil pour apprendre à se lire.*

La Clé rassemble les outils des anciens pour que chacun puisse voir ce qui vibre en lui et choisir ce qu'il cultive. Ces outils sont le ciel, l'Arbre de Vie, les traditions et les plantes.

**Auteur :** L.Y.B.R.

## Le site

Le site tient en un seul fichier, `index.html`, sans installation ni serveur. Il s'ouvre sur un grimoire posé sur un bureau : on choisit sa langue, on tourne la clé, et le livre s'ouvre.

**Langues :** français, anglais, espagnol, portugais, allemand, néerlandais, russe, chinois et hindi.

## Les parties

0. **Genèse**, en 14 pages : d'où vient cette pensée. On y trouve les sept cieux, la Sagesse (Hokhma) comme serveur du code source, et l'implémentation de ce code dans les sept corps.
1. **La création** : la descente de la lumière à travers l'Arbre de Vie, lue par plusieurs traditions (Kabbale, Égypte, Inde, Chine, Kongo, Dogon…).
2. **Le ciel** : le vrai ciel à une date et un lieu donnés, sur cinq mille ans, avec le thème et sa synthèse.
3. **Le travail intérieur** : les sept planètes reliées aux sept centres.
4. **La guérison** : les plantes et les pierres de chaque sphère, avec les pharmacopées européennes, arabes, indiennes, chinoises et africaines.
5. **Le voyage de l'âme** : la remontée porte après porte.
6. **Les mythes** : les créatures et les mondes de chaque sphère.
7. **L'atelier** : une méditation guidée par le souffle.

## Avertissement

La Clé propose une lecture symbolique, issue des traditions. Ce n'est ni un oracle, ni un avis médical, ni une religion. Chaque tradition y parle d'elle-même, et les sources sont citées dans l'atlas.

## Publication sur GitHub Pages

Dans **Settings → Pages**, choisis la branche `main` et le dossier `/ (root)`. Le fichier `.nojekyll` est déjà présent.
